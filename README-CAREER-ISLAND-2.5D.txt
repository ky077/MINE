生涯探索島 2.5D 版本

本次更新：
- 只替換 01 career 生涯探索島的模型。
- 使用 Three.js 基本幾何體與 MeshBasicMaterial，採用清楚色塊、等角視覺與分層地形。
- 包含浮空岩層、草原丘陵、山脈、森林、探索道路、木橋、職涯探索基地、瞭望塔及職業體驗小屋。
- 不使用 GLB，不需要 Blender，也不需要額外模型檔。
- 原本其他四顆星球、作品資料、互動與 UI 保持原狀。

啟動：
1. 解壓縮整個網站資料夾。
2. 使用 VS Code Live Server 開啟 index.html，或在資料夾執行 python -m http.server 8000。
3. 開啟 http://localhost:8000

技術提醒：仍需網路載入 Three.js CDN。建議使用桌面 Chrome / Edge。
