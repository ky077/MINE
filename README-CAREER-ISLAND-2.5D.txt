五座主題浮島 2.5D 版本

五顆星球已統一改為可互動的浮島場景：
- 生涯探索：群山、瞭望塔、探索基地、體驗小屋與瀑布。
- 華語學習：中式學堂、寶塔、石橋、櫻花與瀑布。
- 閱讀素養：圖書館、打開的書、書架與林地。
- 學習診斷：研究中心、資料塔、晶體與群山。
- 研究學術：校園主樓、鐘塔、觀測台、噴泉與花樹。

每座浮島都有分層岩盤、草地、背後的彩色星體與光環。模型由 Three.js 幾何體繪製，
不依賴額外模型檔；拖曳、縮放、點擊與作品資料面板沿用原本互動。

新增中央主星球（星際燈塔／靈感生命樹兩種預覽造型）與五條發光科技空橋。
主題星球大小依各分類作品數量自動計算，五座星球以分散方式圍繞主星球。
兩張高細節造型概念圖存於 assets/concepts，可由網站右上角開啟選擇器比較。

請使用本機 HTTP Server 開啟 index.html，並保持網路連線以載入 Three.js CDN。
