專案網站截圖放在此資料夾。

資料夾與檔名規則：
  img/原始作品ID/序號.png

範例：
  img/
  ├── 00001/
  │   ├── 1.png
  │   ├── 2.png
  │   └── 3.png
  ├── 00002/
  │   ├── 1.png
  │   └── 2.png
  └── ...

系統會依 data.js 中每筆作品的 photoNum 決定顯示張數。
例如 id = "00001"、photoNum = 3，網站會依序載入：
  img/00001/1.png
  img/00001/2.png
  img/00001/3.png

注意：
1. 資料夾名稱使用原始五位數作品 ID。
2. 圖片檔名從 1.png 開始連續編號，不需補零。
3. 圖片格式使用 PNG。
4. photoNum 必須與實際要顯示的圖片張數一致。
